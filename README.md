# Bedrock Voice Assistant

An AI-powered voice assistant built using AWS services:
- Amazon Transcribe (Speech-to-Text)
- Amazon Bedrock (LLM reasoning)
- Amazon Polly (Text-to-Speech)

This project demonstrates an end-to-end AI voice pipeline suitable for
enterprise and healthcare-style use cases.

---

## 🚀 Features

- Push-to-talk voice interaction
- Speech → LLM → Speech pipeline
- AWS-native security (IAM-based)
- Modular and extensible architecture
- Production-style service orchestration

---

## 🧱 Tech Stack

- Node.js + TypeScript
- Express
- Amazon Bedrock (Claude)
- Amazon Transcribe
- Amazon Polly
